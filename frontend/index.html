Operator Manual

How to Use the Translator

Translate Audio

Arm the recorder, speak a short Na'vi phrase, then stop the capture. You can also load an audio file if you already have a recording.

Translate Text

Type any Na'vi phrase and launch the translation signal. The readout includes the English output plus a word-level lexicon match.

Contribute

Submit new words to help grow the dictionary. Pronunciation audio is optional and will be reviewed alongside the text entry.

Pipeline Status

Open the runtime view to inspect backend health, model readiness, and the linked tooling used to operate the training and serving stack.
